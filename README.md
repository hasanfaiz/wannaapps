# WannaApps Homepage Exact Next.js Build

This project serves the approved `wannaapps_homepage_v1/index.html` exactly as the homepage.

No React conversion has been applied to the UI, so the visual output should match the approved HTML preview.

## Run locally

```bash
npm install --no-audit --no-fund --legacy-peer-deps
npm run dev
```

Open:

```text
http://localhost:3000/
```

## Build

```bash
npm run build
npm start
```

## Important

The homepage HTML is stored at:

```text
public/index.html
```

Assets are stored at:

```text
public/assets/
```

Do not edit the UI in React yet. This is the exact homepage approval build.
